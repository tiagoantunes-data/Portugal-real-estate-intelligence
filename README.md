# Portugal Real Estate Intelligence

Datasets limpos e organizados sobre o mercado imobiliário português, construídos a partir de fontes públicas (INE, IMPIC).

## Objetivo

Infraestrutura de dados para análise do mercado imobiliário português — preços, transações e tendências por região e trimestre.

## Datasets disponíveis

| Dataset | Fonte | Período | Granularidade |
|--------|-------|---------|---------------|
| Índice de Preços da Habitação | INE | 2009–2025 | Trimestral |
| Transações de Alojamentos Familiares (€) | INE | 2009–2025 | Trimestral × NUTS II |

## Estrutura
## Stack

- Python + Pandas — limpeza e transformação
- DuckDB — análise local
- Power BI — visualização
